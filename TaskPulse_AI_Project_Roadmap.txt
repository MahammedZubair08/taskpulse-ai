# TaskPulse AI — Project Progress & Roadmap

## 1. Project Vision

TaskPulse AI is an AI-powered task management system that converts information
from natural language, emails, messages, calendars, and other sources into
structured, actionable tasks.

Long-term vision:

Emails + WhatsApp + Calendar + Chat/User Input + Other Sources
                            ↓
                       TaskPulse AI
                            ↓
              Understanding / Extraction
              Deadline / Priority Detection
              Planning / Scheduling
                            ↓
                           Tasks
                            ↓
                      PostgreSQL
                            ↓
                  Dashboard / Reminders

### Task APIs
- POST /api/tasks
- GET /api/tasks

- DELETE /api/tasks/{id}

### Task Filtering
- Filter by status
- Filter by priority

### Validation
- Title required, maximum 200 characters
- Description maximum 5000 characters
- Deadline must be in the future
- Estimated duration: 1–1440 minutes

### Task Ownership / Security
Tasks belong to the authenticated user. User-specific queries such as
findByIdAndUserId(...) prevent users from accessing other users' tasks.

## 4. Completed — AI Backend

### Gemini Task Extraction

Natural-language example:

"Finish my DBMS assignment by Friday, high priority, it should take around
2 hours."

Gemini extracts structured information such as:

{
  "title": "Finish DBMS assignment",
  "priority": "HIGH",
  "deadlineExpression": "by Friday",
  "estimatedDurationMinutes": 120
}

### AI Preview Flow

User Input
    ↓
Gemini
    ↓
Structured Task
    ↓
Editable AI Preview
    ↓
User edits if necessary
    ↓
User confirms
    ↓
Task saved

The AI preview allows editing of:
- Title
- Description
- Priority
- Deadline
- Estimated duration

### Deadline Parser

Implemented DeadlineParser supporting expressions such as:
- today
- tomorrow
- in 3 days
- Monday
- next Monday
- ISO dates
- by Friday
- before Monday
- time expressions such as tomorrow at 5 PM

### AI Validation
- Empty title detection
- Title length validation
- Priority validation
- Duration validation
- Invalid AI response detection

### AI Retry Handling
Gemini requests have retry handling for temporary failures.

### AI Rate Limiting
AI requests are rate-limited to:
- Control Gemini API usage
- Control costs
- Reduce abuse
- Protect the backend

### AI Response Caching
AI task extraction uses caching to avoid unnecessary repeated Gemini requests.

## 6. Current AI Architecture

Natural Language
       ↓
POST /api/ai/extract-task
       ↓
Gemini API
       ↓
AITaskResponse
       ↓
DeadlineParser
       ↓
Editable AI Preview
       ↓
User Confirmation
       ↓
POST /api/ai/tasks
       ↓
TaskService
       ↓
PostgreSQL

Important:
The confirmation step should NOT call Gemini again. Gemini is used for
extraction; the approved structured task should be saved directly.
